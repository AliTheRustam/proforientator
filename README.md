# Сайт-профориентатор «От интересов до профессии»

Практико-ориентированный проект по профориентации школьников.

## Что это

Онлайн-тест из 8 вопросов определяет, какие профессии близки пользователю,
и показывает подробные карточки: реальные рабочие задачи, навыки, плюсы,
честные минусы, пути обучения и блок «Попробуй сейчас».

## Данные о рынке труда

Цифры вакансий и зарплат взяты с [hh.ru](https://hh.ru) (данные на 10.10.2026).

## Технологии

Чистые HTML + CSS + JavaScript

## Структура

```
index.html      — страница
css/style.css   — стили
js/data.js      — контент: 6 профессий + вопросы теста
js/app.js       — логика теста и каталога
```
